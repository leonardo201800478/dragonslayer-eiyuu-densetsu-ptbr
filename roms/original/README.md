# ROM original local

Coloque aqui sua cópia original de **Dragon Slayer: Eiyuu Densetsu**, obtida legalmente, para uso local com as ferramentas do projeto.

- Não distribua nem envie a ROM ao GitHub ou a este repositório.
- O conteúdo desta pasta é ignorado pelo Git; somente este arquivo de instruções é versionado.
- Use o caminho `roms/original/jogo.bin` ao executar a ferramenta, ajustando o nome conforme o arquivo local.
- A licença MIT do projeto cobre somente o código original deste repositório, não o jogo nem a ROM.
